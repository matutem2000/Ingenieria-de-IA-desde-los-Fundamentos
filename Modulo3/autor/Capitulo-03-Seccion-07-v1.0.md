# Capitulo 03 - Sección 07

# Estrategias para optimizar el consumo de tokens

Optimizar tokens reduce costos, mejora la latencia y permite incorporar información de mayor valor.

## Estrategias

- Eliminar contexto redundante.
- Recuperar solo documentos relevantes.
- Limitar ejemplos few-shot.
- Normalizar respuestas de herramientas.
- Mantener instrucciones compactas.

## Métricas

- Tokens promedio por solicitud.
- Tokens de entrada y salida.
- Costo por conversación.
- Tiempo de respuesta.

## Resumen

Toda aplicación profesional debe medir y optimizar continuamente el consumo de tokens.

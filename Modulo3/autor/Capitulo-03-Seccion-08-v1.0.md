# Capitulo 03 - Sección 08

# Patrones de administración del contexto

Existen varios patrones arquitectónicos.

## Sliding Window

Conserva únicamente las últimas interacciones.

## Summary + Window

Mantiene un resumen histórico junto con los mensajes recientes.

## RAG First

Recupera conocimiento únicamente cuando resulta necesario.

## Memoria + Historial + RAG

Combina los tres mecanismos, asignando una responsabilidad específica a cada uno.

## Resumen

No existe un patrón universal; la elección depende del dominio, el costo y la complejidad de la solución.

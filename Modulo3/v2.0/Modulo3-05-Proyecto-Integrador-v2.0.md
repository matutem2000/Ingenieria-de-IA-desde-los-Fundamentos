# Proyecto Integrador

## Objetivo

Diseñar una plataforma de IA empresarial aplicando todos los conceptos del módulo.

## Entregables

- Documento de arquitectura.
- ADR principales.
- Diagramas.
- Diseño del contexto.
- Estrategia de memoria.
- Estrategia de recuperación.
- Diseño de herramientas.
- Evaluación de costo y rendimiento.

## Criterios de aprobación

- Coherencia arquitectónica.
- Escalabilidad.
- Seguridad.
- Mantenibilidad.
- Calidad del contexto.

# Revisión técnica y editorial — Módulo 12

## Dictamen

El proyecto integrador conecta arquitectura, RAG, agentes, seguridad, despliegue, evaluación y observabilidad. Los capítulos 9 y 10 cambian hacia transformación empresarial y quedan demasiado breves para funcionar como cierre demostrable del proyecto.

## Hallazgos prioritarios

1. Definir entregables verificables, criterios de aceptación, datos de prueba y evidencia de ejecución.
2. Una lista de bloqueo y delimitadores XML no neutralizan prompt injection; solo aportan señales y separación semántica.
3. Aplicar mínimo privilegio, aprobación de acciones críticas, límites de gasto, sandbox y parada segura.
4. Exigir trazabilidad entre ADR, amenaza, control, prueba, métrica y resultado.
5. Convertir el cierre en defensa arquitectónica: decisiones, trade-offs, deuda conocida y plan operativo.

## Correcciones producidas

Se generaron 60 versiones corregidas. Se reformuló la defensa contra prompt injection para evitar una falsa sensación de seguridad y se incorporaron controles de impacto.

## Decisiones editoriales

- Se mantuvo el capítulo como evaluación final, pero se evitó que pareciera solo un cuestionario.
- Se reforzó el foco del libro: desarrollar criterio profesional antes que memorizar herramientas.
- Se usó terminología oficial: Inteligencia Artificial (IA), Machine Learning (ML), Deep Learning (DL), Large Language Model (LLM), Context Window, Embedding, Retrieval-Augmented Generation (RAG), Fine-tuning e Inference.
- Se evitó atribuir conciencia, comprensión humana o conocimiento absoluto al modelo.
- Se priorizaron escenarios empresariales y decisiones arquitectónicas.
- Se conectó explícitamente el cierre del Módulo I con el Módulo II sobre Prompt Engineering Profesional.

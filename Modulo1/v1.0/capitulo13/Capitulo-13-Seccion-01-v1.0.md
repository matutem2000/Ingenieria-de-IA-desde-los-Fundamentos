# Introducción

Hasta este punto del libro se desarrollaron los fundamentos necesarios
para comprender cómo funcionan los modelos, cómo diseñar arquitecturas,
cómo integrar componentes y cuáles son las limitaciones de la
Inteligencia Artificial.

Sin embargo, ningún arquitecto desarrolla criterio únicamente leyendo
teoría.

El conocimiento técnico se consolida cuando las decisiones producen
resultados observables.

Por ese motivo, este capítulo introduce una serie de laboratorios
diseñados para reproducir situaciones similares a las que aparecen
durante proyectos reales.

Cada práctica tendrá un objetivo concreto, un escenario definido y un
resultado verificable.

------------------------------------------------------------------------

# Filosofía de los laboratorios

Los ejercicios propuestos no buscan enseñar comandos de memoria.

Su finalidad consiste en que el lector experimente cómo pequeñas
decisiones de diseño modifican el comportamiento de una solución basada
en IA.

Cada laboratorio responderá cuatro preguntas:

1.  ¿Qué problema se intenta resolver?
2.  ¿Qué decisión debe tomar el arquitecto?
3.  ¿Qué ocurre al modificar esa decisión?
4.  ¿Qué conclusiones pueden generalizarse a otros proyectos?

# Estructura común

Todos los laboratorios del libro seguirán la misma estructura:

  Sección      Propósito
  ------------ -----------------------------
  Objetivo     Qué se aprenderá
  Escenario    Problema a resolver
  Requisitos   Herramientas necesarias
  Desarrollo   Pasos reproducibles
  Validación   Cómo comprobar el resultado
  Reflexión    Lecciones obtenidas

Esta organización facilita comparar resultados entre distintos
ejercicios y favorece la repetición de experimentos.

------------------------------------------------------------------------

# Ideas clave

-   Experimentar es parte del proceso de ingeniería.
-   Los laboratorios buscan desarrollar criterio, no repetir
    procedimientos.
-   La observación y la medición son tan importantes como la
    implementación.

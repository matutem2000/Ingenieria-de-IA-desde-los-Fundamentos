# Introducción

En el capítulo anterior desarrollamos una idea central: la Inteligencia
Artificial no consiste en herramientas, sino en principios.

Ahora comenzaremos a estudiar el mecanismo que permitió el surgimiento
de los sistemas modernos de IA.

La pregunta ya no es **qué** puede hacer un modelo.

La pregunta es **cómo** llega a hacerlo.

------------------------------------------------------------------------

# Programar versus entrenar

Durante décadas, desarrollar software significó traducir reglas de
negocio en código.

El comportamiento del sistema dependía exclusivamente de las
instrucciones escritas por los desarrolladores.

En Inteligencia Artificial ocurre algo diferente.

El desarrollador ya no especifica todas las reglas.

Construye un proceso para que el sistema descubra patrones a partir de
ejemplos.

Por esa razón hablamos de **entrenamiento** y no simplemente de
programación.

------------------------------------------------------------------------

# ¿Qué significa aprender?

Desde una perspectiva ingenieril, aprender significa modificar un modelo
para mejorar su desempeño frente a una tarea determinada utilizando
experiencia previa.

Esa experiencia normalmente adopta la forma de datos.

El modelo procesa ejemplos, produce resultados, compara esos resultados
con el comportamiento esperado y ajusta internamente millones o miles de
millones de parámetros.

Este ciclo se repite una y otra vez hasta alcanzar un nivel de desempeño
aceptable.

Es importante observar que el modelo no "comprende" en el sentido humano
del término.

Optimiza una función matemática para reducir el error cometido durante
el entrenamiento.

------------------------------------------------------------------------

# Una analogía útil

Aprender a lanzar una pelota no consiste en memorizar una única posición
del brazo.

Después de cada intento realizamos pequeños ajustes.

Con suficiente práctica, esos ajustes producen un movimiento cada vez
más preciso.

El entrenamiento de un modelo sigue una lógica similar.

No memoriza una única respuesta.

Ajusta progresivamente sus parámetros para reducir el error acumulado.

La analogía ayuda a comprender la idea general, aunque el proceso
matemático real sea considerablemente más complejo.

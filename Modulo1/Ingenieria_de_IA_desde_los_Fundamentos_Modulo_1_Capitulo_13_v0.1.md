------------------------------------------------------------------------

# Objetivos

El propósito de este capítulo es consolidar los conocimientos adquiridos
en los doce capítulos anteriores mediante ejercicios prácticos.

No se busca aprender nuevas definiciones.

Se busca desarrollar criterio profesional.

Cada laboratorio reproduce situaciones similares a las que enfrentará un
arquitecto o desarrollador al diseñar soluciones basadas en Inteligencia
Artificial.

------------------------------------------------------------------------

# Recomendaciones generales

Antes de comenzar:

-   Utilizá al menos dos asistentes distintos (por ejemplo ChatGPT y
    Claude).
-   Registrá todas tus observaciones.
-   No busques "la respuesta correcta".
-   Analizá diferencias de comportamiento.

El objetivo es aprender a comparar modelos.

------------------------------------------------------------------------

# Laboratorio 1 --- Comparando modelos

## Objetivo

Observar cómo distintos modelos responden a una misma solicitud.

## Actividad

Realizá exactamente el mismo prompt en:

-   ChatGPT
-   Claude
-   Gemini (si está disponible)
-   Un modelo local (si disponés de uno)

Compará:

-   claridad;
-   velocidad;
-   profundidad;
-   organización;
-   precisión;
-   facilidad de lectura.

## Reflexión

¿Existe realmente un "mejor modelo" o depende del problema?

------------------------------------------------------------------------

# Laboratorio 2 --- Temperatura

Elegí un mismo prompt.

Ejecutalo utilizando distintos valores de temperatura.

Respondé:

-   ¿Qué cambió?
-   ¿Cuál fue más creativo?
-   ¿Cuál fue más consistente?
-   ¿Cuál utilizarías para generar código?

------------------------------------------------------------------------

# Laboratorio 3 --- Tokens

Tomá un prompt muy extenso.

Reducilo aproximadamente a la mitad.

Compará:

-   longitud;
-   calidad;
-   costo estimado;
-   velocidad.

Reflexioná:

¿Cuánta información era realmente necesaria?

------------------------------------------------------------------------

# Laboratorio 4 --- Contexto

Realizá una conversación larga.

Intentá identificar:

-   cuándo el modelo comienza a perder información;
-   qué estrategias permiten mantener la calidad de las respuestas.

Probá:

-   resumir la conversación;
-   comenzar una conversación nueva;
-   reorganizar el contexto.

------------------------------------------------------------------------

# Laboratorio 5 --- Embeddings (conceptual)

Pensá cinco formas distintas de preguntar exactamente lo mismo.

Ejemplo:

-   ¿Cómo cambio mi contraseña?
-   Olvidé mi clave.
-   No puedo ingresar.
-   Necesito recuperar el acceso.
-   Perdí mi contraseña.

Analizá por qué una búsqueda basada en palabras podría fallar y una
búsqueda semántica tendría mayores probabilidades de éxito.

------------------------------------------------------------------------

# Laboratorio 6 --- ¿Necesita IA?

Elegí cinco aplicaciones de tu organización.

Para cada una respondé:

1.  ¿Existe un problema que justifique IA?
2.  ¿Puede resolverse mediante reglas?
3.  ¿Qué beneficios reales aportaría?
4.  ¿Qué riesgos introduciría?

------------------------------------------------------------------------

# Laboratorio 7 --- Arquitectura

Seleccioná un caso real.

Por ejemplo:

-   asistente para documentación;
-   consulta a Data Warehouse;
-   mesa de ayuda;
-   clasificación de expedientes.

Diseñá una arquitectura conceptual indicando:

-   usuario;
-   aplicación;
-   LLM;
-   base de datos;
-   RAG (si corresponde);
-   APIs;
-   validaciones.

No importa la tecnología.

Importa el razonamiento.

------------------------------------------------------------------------

# Laboratorio 8 --- Pensar como un arquitecto

Leé las siguientes frases.

Para cada una escribí una respuesta profesional.

## Caso A

"Necesitamos IA porque todas las empresas la están implementando."

## Caso B

"Compremos el modelo más grande."

## Caso C

"Subamos todos nuestros documentos al modelo."

## Caso D

"Si el modelo respondió, debe ser correcto."

El objetivo es desarrollar criterio y capacidad argumentativa.

------------------------------------------------------------------------

# Desafío final

Elegí un problema real de tu organización.

Respondé:

-   ¿Existe realmente un problema?
-   ¿Conviene utilizar IA?
-   ¿Qué tipo?
-   ¿Qué arquitectura elegirías?
-   ¿Qué modelo utilizarías?
-   ¿Qué riesgos observás?
-   ¿Cómo medirías el éxito del proyecto?

Este ejercicio será la base para los módulos posteriores.

------------------------------------------------------------------------

# Resumen

Los laboratorios constituyen el puente entre la teoría y la práctica.

Su objetivo no es encontrar una única solución correcta, sino
desarrollar la capacidad de observar, comparar y justificar decisiones
técnicas.

Ese será uno de los pilares de todo el libro.

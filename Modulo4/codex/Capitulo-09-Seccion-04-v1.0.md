# Gestión de Riesgos

El gobierno incluye identificar riesgos técnicos, legales, éticos y operativos, asignando responsables y planes de mitigación.

## Contenidos principales

- Políticas de IA.
- Roles y responsabilidades.
- Gestión del ciclo de vida.
- Riesgos y cumplimiento.
- Indicadores de madurez.

## Para recordar

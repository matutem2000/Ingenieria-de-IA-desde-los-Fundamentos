# Módulo 4 – Capítulo 08 – Sección 06

# Resumen

Una arquitectura escalable debe crecer junto con el negocio manteniendo el equilibrio entre rendimiento, resiliencia y costos.

## Conceptos desarrollados

- Escalabilidad.
- Disponibilidad.
- Balanceo.
- Optimización de recursos.
- Continuidad operativa.

## Idea clave

La mejor arquitectura no es la que soporta la mayor carga, sino la que puede crecer de manera controlada, sostenible y económicamente viable.

# Módulo 4 – Capítulo 07 – Sección 03

# Seguridad de Datos

Las bases vectoriales, documentos y conversaciones pueden contener información sensible que debe cifrarse y auditarse.

## Puntos principales

- Riesgos específicos de IA.
- Controles preventivos.
- Monitoreo continuo.
- Buenas prácticas de diseño.
- Gestión del riesgo.

## Conclusión

Incorporar seguridad desde la arquitectura resulta considerablemente menos costoso que corregir vulnerabilidades una vez que el sistema está en producción.

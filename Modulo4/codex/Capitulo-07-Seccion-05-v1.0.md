# Módulo 4 – Capítulo 07 – Sección 05

# Gobierno y Cumplimiento

Las organizaciones necesitan políticas para uso responsable, retención de datos, auditoría y cumplimiento regulatorio.

## Puntos principales

- Riesgos específicos de IA.
- Controles preventivos.
- Monitoreo continuo.
- Buenas prácticas de diseño.
- Gestión del riesgo.

## Conclusión

Incorporar seguridad desde la arquitectura resulta considerablemente menos costoso que corregir vulnerabilidades una vez que el sistema está en producción.

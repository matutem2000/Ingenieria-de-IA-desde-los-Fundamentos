# Módulo 4 – Capítulo 04 – Sección 02

# Componentes de un Agente

Un agente combina un modelo, memoria, herramientas, planificación y mecanismos de observación para resolver objetivos complejos.

## Temas desarrollados

- Arquitecturas de agentes.
- Herramientas y memoria.
- Coordinación entre agentes.
- Patrones de diseño.
- Aplicaciones empresariales.

## Conclusión

El verdadero valor de los agentes no reside únicamente en el modelo de lenguaje, sino en la capacidad de integrar razonamiento, herramientas y procesos para resolver problemas reales.

# Historial de Cambios
**Proyecto:** Ingeniería de IA desde los Fundamentos

Este documento registra los cambios relevantes realizados durante el desarrollo del proyecto.

El formato está inspirado en **Keep a Changelog**, adaptado a un proyecto editorial.

---

# Versionado

El proyecto utiliza el siguiente esquema de versiones:

- **v0.x** → Construcción del contenido.
- **v0.5** → Revisión conceptual.
- **v0.8** → Revisión técnica.
- **v0.9** → Revisión editorial.
- **v1.0** → Publicación.

# LAB_GUIDE.md

# Guía para el Diseño de Laboratorios
Proyecto: Ingeniería de IA desde los Fundamentos

Versión: 1.0

---

# Objetivo

Definir un estándar para todos los laboratorios del libro.

Cada laboratorio debe transformar un concepto teórico en una experiencia práctica que ayude al lector a desarrollar criterio profesional.

---

# Principios

- Aprender haciendo.
- Partir de problemas reales.
- Favorecer el razonamiento antes que la repetición.
- Utilizar herramientas accesibles.
- Priorizar calidad sobre cantidad.

---

# Estructura obligatoria

## 1. Objetivo

¿Qué aprenderá el lector?

## 2. Nivel

- Inicial
- Intermedio
- Avanzado

## 3. Tiempo estimado

Indicar el tiempo aproximado necesario para completar la actividad.

## 4. Prerrequisitos

Conceptos o capítulos necesarios.

## 5. Herramientas

Ejemplo:

- Ollama
- Docker
- Python
- VS Code
- ChatGPT
- Claude

## 6. Escenario

Presentar un problema concreto.

No comenzar por la tecnología.

## 7. Desarrollo

Explicar paso a paso.

Cada paso debe incluir:

- Acción.
- Motivo.
- Resultado esperado.

## 8. Validación

¿Cómo comprobar que el laboratorio fue exitoso?

## 9. Reflexión

Preguntas para desarrollar criterio.

## 10. Desafíos opcionales

Propuestas para profundizar el aprendizaje.

---

# Tipos de laboratorios

- Conceptuales.
- Comparativos.
- Desarrollo de software.
- Arquitectura.
- Evaluación de modelos.
- Seguridad.
- Optimización.
- Casos empresariales.

---

# Buenas prácticas

- Mantener los ejemplos simples.
- Evitar configuraciones innecesarias.
- Explicar el porqué de cada decisión.
- Favorecer la experimentación.

---

# Anti-patrones

Evitar laboratorios que:

- solo consistan en copiar comandos;
- dependan de servicios costosos;
- no tengan un objetivo claro;
- no generen reflexión.

---

# Checklist

Antes de aprobar un laboratorio verificar:

- Objetivo definido.
- Escenario realista.
- Pasos reproducibles.
- Resultado verificable.
- Preguntas de reflexión.
- Desafíos opcionales.
